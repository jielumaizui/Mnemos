# 项目拓扑 - Mnemos

**生成时间:** 2026-08-06 21:10
**项目类型:** 后端 (Python, CLI + Daemon + MCP 混合架构)
**主要语言:** Python 3.10+
**框架:** 自研（无 Web 框架，CLI argparse + 多线程 daemon + MCP stdio server）
**存储:** SQLite 多库（data_dir=`~/.mnemos`）+ 双 Markdown vault（raw=`~/Documents/raw`，wiki=`~/Documents/mnemos`，macOS 默认）
**规模:** 1708 个 Python 文件（core+daemon+integrations ~800，tests 654，scripts 260）

## 4. 数据流图

### 4.1 对话捕获主链路（Agent → Wiki）
```
Agent (Claude/OpenCode/Kimi/…)
  → MCP: integrations/agora.py + integrations/agora_tools/schema.py
  → Facade: core/application/facade.py + core/application/facade_capture.py
  → CaptureService.capture_turn   [core/sync_framework/capture_service.py]
      ├─ 校验+规范化 (payload size policy, hashing)
      │   └─ core/sync_framework/capture_duplicate_policy.py (幂等键)
      ├─ 写 canonical raw (revision 幂等)
      │   └─ core/sync_framework/raw_event_store.py
      │   └─ core/sync_framework/raw_event_identity.py (内容哈希)
      ├─ 入 capture queue (SQLite)
      │   └─ core/sync_framework/capture_queue.py
      └─ Capture-to-Amphora outbox
          └─ core/sync_framework/capture_handoff.py
  → CaptureWorker / Amphora 出库  [core/sync_framework/capture_worker.py]
      └─ core/kia/amphora.py + core/kia/amphora_queries.py
      ├─ 质量门 + duplicate policy
      └─ 入 distill queue (distill_queue.db)
  → DistillationEngine 分块       [core/hephaestus/distillation_engine.py]
      ├─ tokenizer 无损切块 (lossless-visible-v1)
      │   └─ core/hephaestus/chunked_extraction.py
      ├─ KnowledgeExtractor (LLM, 硬校验+自我修正)
      │   └─ core/hephaestus/distillation_extractor.py
      ├─ FragmentMerger (Jaccard 聚类 + LLM 合成/规则回退)
      ├─ 检查点 (execution spec hash, cache hit/miss)
      │   └─ core/hephaestus/distill_execution_spec.py
      │   └─ core/hephaestus/chunk_checkpoint.py
      ├─ LLM backend
      │   └─ core/hephaestus/distill_backend.py
      └─ Action routing
          └─ core/hephaestus/distill_action_router.py
          └─ core/hephaestus/distill_action_store.py
  → TrustedPush 闭环 (mode=shadow/enforce)  [core/trust/]
      core/trust/proposal_queue.py → core/trust/push_decision_gate.py
      → core/trust/write_journal.py → core/trust/knowledge_vault_writer.py
      → core/trust/vault_mutation_service.py
  → 写 Wiki 页面 (vaults.mnemos)
  → WikiProjectionLedger (append-only) + 发布 wiki_page_updated 事件
      [core/wiki_projection_lifecycle.py + core/wiki_projection_publisher.py]
      └→ EventBus → required consumers: knowledge_graph / cognitive_graph /
         relation_embeddings / wiki_search_index / wiki_metrics / moc_navigation
```

### 4.2 事件总线（异步核心）
```

  daemon/wiki_projection_handlers.py (Wiki 投影 endpoint 消费)
```
